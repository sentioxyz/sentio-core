# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue, pull request or discussion for a security vulnerability.

Report it privately instead:

1. Preferred: use GitHub's private vulnerability reporting —
   [report a vulnerability](https://github.com/sentioxyz/sentio-core/security/advisories/new).
2. Alternatively, email support@sentio.xyz with `SECURITY` in the subject.

Please include a description of the issue, affected components or versions, reproduction steps or
a proof of concept, and the impact you believe it has.

We will acknowledge your report within 3 business days and keep you updated while we investigate.
Please give us a reasonable window to ship a fix before disclosing publicly; we are happy to
credit you in the advisory unless you prefer otherwise.

## Scope

This policy covers the code in this repository. Issues in the hosted Sentio platform
(`app.sentio.xyz`) can be reported through the same channels.

## Supported versions

Only `main` is supported. Fixes land on `main` and flow into the next release; we do not backport
to older tags.
